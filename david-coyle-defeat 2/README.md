# The Defeat of David Coyle

A fun tribute website about the legendary (and very green) defeat of David Coyle.

## Files included
- `index.html` — the full website
- `david-coyle.jpg` — the iconic photo

## How to put this online (free)

### Option 1: Netlify (Easiest)
1. Go to [https://app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag and drop this entire folder
3. Netlify gives you a live link instantly (example: `https://random-name-123.netlify.app`)

### Option 2: GitHub Pages
1. Create a new GitHub repository
2. Upload these two files
3. Go to Settings → Pages → set Source to main branch
4. Your site will be live at `https://yourusername.github.io/repository-name`

### Option 3: Cloudflare Pages
1. Go to [https://pages.cloudflare.com](https://pages.cloudflare.com)
2. Create a project and upload the folder

---

Once it's online, Google can eventually find it if people link to it or you submit the URL to Google Search Console.
